# Draggable Portal

Simple draggable notes portal built with React + TypeScript.

## Features

- Drag portal around screen
- Create notes
- Rename notes
- Delete notes
- Save to localStorage
- Sidebar notes list
- Clean minimal UI

---

# Install

```bash
npm install
```

# Run

```bash
npm run dev
```

---

# Tech Stack

- React
- TypeScript
- CSS
